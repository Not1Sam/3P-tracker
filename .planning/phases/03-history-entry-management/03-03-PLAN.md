- `handleDelete()`: Calls `deleteEntryWithUndo(id, type, toastCallback, refreshCallback)`. The toast callback shows the Toast component. After delete, call `router.back()` to return to previous screen.

  - Location: `📍 {entry.locationCity}` if present, with lat/lng below. Display only — locked per D-06.
  - Comment: Show comment text if present, or "No comment" placeholder.
  - For piss entries only: Smell level display (emoji + label from SMELL_OPTIONS).

**Edit modal (per D-05):**
- `<EditEntryModal visible={showEditModal} entry={entry} type={type} onClose={() => setShowEditModal(false)} onSaved={() => { setShowEditModal(false); loadEntry(); }} />`
- Modal renders on top of the detail screen (detail screen remains visible behind).

**Toast:**
- Render `<Toast visible={showToast} message={toastMessage} onUndo={handleUndo} onDismiss={() => setShowToast(false)} />` for delete undo.
