## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → version endpoint | Untrusted network — version response could be tampered with |
| client → download URL | Opens arbitrary URL from version endpoint in browser |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-01 | Tampering | version endpoint response | medium | mitigate | Use HTTPS for endpoint, validate response has required fields before using |
| T-09-02 | Elevation of Privilege | APK download URL | low | accept | User explicitly taps "Download Update" — URL opened in browser, not auto-installed |
| T-09-03 | Information Disclosure | version endpoint | low | accept | Endpoint reveals current version — low risk, common practice |
</threat_model>
