  <action>
1. Create `public/manifest.json` with PWA metadata (per D-09). Use `"short_name": "3P Tracker"`, `"name": "3P Tracker - Log & Compete"`, `"display": "standalone"`, `"orientation": "portrait"`, `"theme_color": "#8B4513"` (playful primary), `"background_color": "#FFF8F0"` (playful background). Include icon entries for 64x64 (favicon), 192x192, and 512x512. Set `"start_url": "."`.

2. Create placeholder icon files at `public/logo192.png` and `public/logo512.png`. Since we cannot generate real PNGs in-code, create a minimal valid PNG (1x1 pixel transparent) as a placeholder. The user must replace these with real app icons before production deployment. The 192x192 and 512x512 sizes are required by iOS for "Add to Home Screen" (per research pitfall 3).

3. Create `workbox-config.js` at project root for Workbox CLI service worker generation (per D-08 — cache-first strategy). Configure:
   - `globDirectory: 'dist'` — processes Expo web export output
   - `globPatterns: ['**/*.{js,html,css,png,ico,json,woff2,woff,ttf}']` — cache all app assets
   - `swDest: 'dist/sw.js'` — output service worker
   - `clientsClaim: true` and `skipWaiting: true` — activate immediately
   - `navigateFallback: '/index.html'` — SPA routing
   - `navigateFallbackDenylist: [/^\\/_/, /\\/[^/]+\\.[^/]+$/]` — skip API/static file routes
   - Runtime caching: NetworkFirst for Supabase API calls (`/^https://.*\\.(supabase\\.co|supabase\\.in)\\/.*$/i`, cacheName `'supabase-cache'`, maxEntries 50, maxAgeSeconds 3600), StaleWhileRevalidate for all other HTTPS (`/^https?.*/`, cacheName `'offlineCache'`, maxEntries 200)

4. Create `scripts/build-pwa.sh` — a simple script that runs `expo export -p web` followed by `npx workbox-cli generateSW workbox-config.js`. Make it executable (`chmod +x`). Add a `"build:web"` script to package.json: `"expo export -p web && npx workbox-cli generateSW workbox-config.js"`.

5. Install workbox-cli as dev dependency: `npm install -D workbox-cli`.

6. Verify: manifest.json is valid JSON with standalone display and correct icons. workbox-config.js has correct glob patterns and runtime caching rules. build-pwa.sh exists and is executable.
